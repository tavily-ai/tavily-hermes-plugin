# Security

Report vulnerabilities privately through this repository's GitHub Security
Advisories when enabled, or Tavily's support channel. Never post API keys,
tokens, authorization headers, or private research contents in public issues.

The plugin has no executable runtime or credential store. It uses Hermes's MCP
implementation and Tavily's hosted service. Include the plugin commit, Hermes
version, affected auth mode, and a redacted reproduction when reporting a problem.
